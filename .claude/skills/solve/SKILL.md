# 계산 단계 (03_cases)

목표: `case_spec.yaml` → `./Allrun` → `<케이스>/report/flow_report.md` → **사용자 검토 대기**.

## 절대 규칙
1. **진입 조건**: `02_mesh/MESH_APPROVED`가 없으면 계산하지 않는다.
2. **물리 값은 사용자 승인 없이 바꾸지 않는다.** `status: given`인 값(온도, 유속, 조성, 벽 조건, 촉매 물성, 반응 계수)은 물론, `assumed`/`estimated` 값도 바꿀 때는 먼저 사용자에게 묻는다. 수렴이 안 된다고 물성이나 경계조건을 바꿔서 해결하지 않는다.
3. **수치 설정(이완계수, 반복 수, 스킴)은 조정 가능**하지만, 바꾼 내용과 이유를 PROGRESS.md 결정 기록에 남긴다. 1차 정확도(upwind)로 바꿔서 수렴시킨 결과는 최종 결과로 보고하지 않는다.
4. **설정은 `case_spec.yaml`에서만 바꾼다.** 케이스 폴더의 Dict는 자동 생성물이다.
5. **결과 보존**: 이미 결과가 있는 케이스는 덮어쓰지 않는다. 조건을 바꿀 때는 `meta.name`을 새로 정한다. `--force`는 사용자가 원할 때만 쓴다.
6. 케이스 이름은 영문자로 시작한다 (숫자로 시작하면 .gitignore가 시간 폴더로 오인).

## 작업 순서
1. PROGRESS.md 확인, `case_spec.yaml`의 assumed/estimated 항목 중 이번 계산에 영향이 큰 것을 사용자에게 상기
2. `cd 03_cases && ./Allrun` (8코어 기준 23만 셀, 3000회 ≈ 10분 내외. 오래 걸리면 `tail -f`로 진행 확인)
3. 보고서 판정·WARN·그림을 요약해 보고하고 **멈춘다.** 결과 해석(유속 분포, 압력손실)도 짧게 덧붙인다.
4. PROGRESS.md 갱신, 커밋

## 판정 기준 (check_case.py)
- FAIL: 솔버 발산(NaN), 질량 보존 오차 > 0.5 %
- WARN: 촉매층 ΔP 모니터 마지막 200회 변동 > 0.5 %, 순간값/평균값(fieldAverage) 차이 > 0.5 % (촉매층 ΔP, 전체 ΔP, 균일도 γ), 촉매 내 물리 속도가 논문 다공성 계수 산출 범위(1.75~3.0 m/s) 밖, 층별 압력손실이 1D 이론과 15 % 이상 차이
- INFO(판정 제외): 잔차, 최대 반복 도달, 평균 필드가 있을 때의 전체 ΔP 모니터 변동. 평균 필드가 없으면 전체 ΔP 모니터도 WARN 판정
- 수렴은 **잔차가 아니라 모니터 안정성과 순간/평균 차이**로 본다 (2026-11-11 사용자 결정). 확장부·출구 덕트 박리 유동 때문에 정상 RANS 잔차는 p ~4e-2, k ~8e-3에서 평평해지지만 촉매층 결과는 순간/평균 차이 0.00 % (flow_2layer_avg 진단).
- 평균 필드(`solver.field_average`)를 켜 두면 균일도·압력손실은 UMean/pMean으로 판정한다.

## 이 케이스의 모델링 메모
- 솔버 porousSimpleFoam: 가로 저항이 축의 1e4배인 비등방 다공성은 simpleFoam+fvOptions로는 압력식이 거의 안 풀림. porosityProperties(암시적 처리)를 쓴다.
- 다공성 변환: OpenFOAM은 표면속도 U = εu 기준. 논문 식 (3)에서 d = 1/k, f = 2cF/√k.
- 촉매층 내부 난류는 `laminarize_porous`로 k를 작게 고정 (채널 Re 수백, 층류).
- 다공성 경계면 첫 셀의 셀 중심 속도는 왜곡되므로 유속 분포는 층 깊이 1/3 지점에서 평가한다. 면 유량(질량 보존)은 정확하다.
- 질량유량은 입구 속도 × 입구 덕트 면적이고, 덕트 직경은 형상 단계의 가정값이다. 보고서의 질량유량을 사용자에게 꼭 확인받는다.

## 3-2단계 (reacting, 미구현) 계획
`stage: reacting`은 아직 지원하지 않는다. 사용자 요청 시 다음 순서로 진행:
1. 전용 솔버 작성 (porousSimpleFoam 기반 + 에너지 + 화학종 NO, NH3, O2, H2O + 표면 NH3 피복률 X_NH3* 국소 수지 + 반응열 + 다공성 유효 열전도도 식 (5)). 반응 계수는 case_spec.yaml `catalyst.kinetics`.
2. **논문의 1D 마이크로리액터 검증(Figure 4, Koo et al. 조건) 재현으로 솔버를 먼저 검증**한 뒤 3층 반응기에 적용.
3. 비교 기준: 측정 NOx 전환율 88.8~99.7 % (validation.measured_NOx_conversion_range).
